# Маяк · отдельный визуальный этюд

Маленькая художественная сцена для оценки формы, цвета, глубины и камеры. Это самостоятельный образец, не новая версия игровой демки. Сюжета, игровых действий, сохранений и телеметрии здесь нет.

Запуск из этого каталога:

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/`. Нужен HTTP, а не `file://`, из-за ES-модулей. Сетевые CDN не требуются. Полный экран включается по нажатию и зависит от браузера; системные панели телефона могут оставаться.

«Сравнить картинку» открывает варианты рендера. Оба получают одну геометрию и камеру. «Текущий» — исправленная batched WebGL1 версия собственного подхода, без дорогого копирования GL-кадра в Canvas. Three.js r180 использует WebGL2; при его отсутствии показывается явное сообщение. Canvas — отдельный упрощённый запасной режим. Базовый и художественный варианты различаются цветом и нормалями на одной геометрии. Ветер можно отключить, настройка уменьшения движения ОС учитывается при запуске.

На телефоне оценивать прежде всего ракурс, форму берега и читаемость смотрителя. Локальные показатели не отправляются наружу и не обещают одинаковую скорость на всех устройствах. Эта сцена не читает прогресс из рабочей игры.

Осмотр в версии `visual-lab-2026-10-22-r2`: выберите «Общий вид», «Маяк крупно» или «Берег крупно». Разводите/сводите два пальца либо нажимайте `+` / `−` для масштаба; один палец поворачивает сцену по горизонтали. На компьютере можно использовать колесо мыши. «Сброс» возвращает общий вид и исходный масштаб. Камера ограничена по расстоянию и высоте; смена renderer сохраняет тот же план. Жесты над кнопками и прокрутка панели сравнения не управляют камерой.

Все формы сцены созданы для этого этюда. Summerhill и Alto — художественные ориентиры; их изображения, модели и звуки в пакет не включены.
